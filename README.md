# Лабораторная работа: Циклы с ветвлением

## Автор
Тенц Ангелина (Вариант 30)

## Цель
Научиться обрабатывать серию аргументов обязательным циклом for и выбирать формулу на каждой итерации с помощью условий. 
## Описание
Программа рассчитывает параметры потока воды при разной скорости движения воды в трубе: число Рейнольдса, коэффициент трения, потерю давления, необходимую для преодоления потери мощность.
## Исходные данные
- Длина трубы: 4 м
- Внутренний диаметр: 10 мм
- Плотность воды: 998 кг/м^3
- Кинематическая вязкость: 0.000001 м^2/с
- Средняя скорость: 0.02, 0.05, 0.1, 0.2, 0.4, 0.6, 1 м/с

## Ожидаемые результаты
Программа выводит таблицу результатов. "w, m/s" - средняя скорость потока в м/с, "Re" - число Рейнольдса, "lambda" - коэффициент трения, "delta p, Pa" - потеря давления (Па), "P, W" - мощность (Вт).
